# SuaEscola 
This app is a MVP in construction, for a school management system.
You can add a student and a related guardian.

### How to run the project
- Activate the virtual environment
- Execute the command: `pip install -r requirements.txt`
- Run the project:
`(env)$ flask run --host 0.0.0.0 --port 5000 --reload`
- Open the browser and access the address: `http://localhost:5000/`
- Enjoy!
